## Quick Steps for Remaining 2 Xcode Screenshots:

1. **`01_CoreData_Graph.png` (Core Data Graph Editor in Xcode):**
   - In Xcode, click `StudentOrganizer.xcdatamodeld` in the Project Navigator.
   - At the bottom-right corner of the editor canvas, click the **Graph** view button (two small connected squares).
   - Press **⌘⇧4** on your Mac keyboard, drag to select the three entity boxes (`Subject`, `TaskItem`, `Note`), and save the screenshot as `Deliverables_Screenshots/01_CoreData_Graph.png`.

2. **`09_Xcode_Run_Destination.png` (Xcode Destination Toolbar):**
   - Connect your iPhone to your Mac via USB and select it from the top toolbar device menu in Xcode (or select your approved Simulator).
   - Press **⌘⇧4**, drag to select the Xcode window header showing the project name and destination device name, and save the screenshot as `Deliverables_Screenshots/09_Xcode_Run_Destination.png`.
